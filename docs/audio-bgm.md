# 星空氛围背景音乐（Web Audio 程序化合成）· 设计与答辩口径

> 新增「背景音乐」功能：一段持续、缓慢、可循环的星空氛围纯音乐。
> **不使用任何外部音频文件**——所有声音由 Web Audio API 在浏览器内实时合成，
> 离线可播、无版权风险、体积为零，参数与随机种子固定，听感可复现。

## 1. 声景设计（`src/audio/StarfieldMusic.js`）

```
铺底和弦（D♭ 大调）     五声音阶钟琴点缀        空间风噪
5 音 × 双失谐振荡   →   随机 2.4~6.6s 轻触键 →   带通噪声（极低音量）
      ↓                       ↓                      ↓
 缓慢呼吸低通(40s)     立体声声像 ±0.6          320Hz 慢速游移
      └────────────┬──────────┴──────────────────────┘
              混响总线（卷积混响 3.4s 衰减）
                dry 0.5 / wet 0.55
                       ↓
             主增益（音量滑杆）→ 压缩器 → 输出
```

- **铺底**：D♭2 / A♭2 / D♭3 / F3 / A♭3 五个音，每音一对轻微失谐（±4~6 cent）的三角波与正弦，
  经 0.025Hz（40 秒周期）开合的低通滤波 + 0.05Hz 呼吸振幅——缓慢、温暖、无节奏压迫感。
- **和声层**：每 22 秒在两个色彩和弦（Fm7 / G♭maj7）之间做 5s 起音、15s 保持、6s 收尾的交叉淡化，
  营造"星系缓慢转动"的色彩变化。
- **钟琴点缀**：D♭ 大调五声音阶（天然协和），随机间隔 2.4~6.6s、随机声像的轻触键，
  每个音 2.8s 指数衰减、带二次泛音——像远处的星尘闪光。
- **空间风噪**：带通噪声（中心 320Hz、慢速游移）仅 0.018 增益，提供星际尘埃底噪。
- **混响**：程序生成的 3.4s 指数衰减脉冲响应（立体声），全部声音走混响总线，深空长尾。
- 总输出经软压缩器（-18dB / 3:1）兜底，音量默认 65%，长时间聆听不刺耳。

## 2. 交互与工程细节

- **自动播放策略**：默认开启，但 AudioContext 只在**首次用户手势**（pointerdown）后创建/恢复；
  用户关掉后再次打开立即恢复。
- **持久化**：开关与音量写入 `localStorage: kmu:bgm`，刷新后保持偏好。
- **切后台自动挂起**：`visibilitychange` 时 suspend，回到页面 resume（省电、避免后台占用）。
- **关闭即淡出**：关闭后主增益 0.7s 时间常数淡出，1.8s 后挂起上下文；所有节点保留以便秒开。
- **控件**：星系控制台「背景音乐」开关 + 「音乐音量」滑杆（移动端收起音量行，用系统音量）。
- **验收钩子**：`window.__music.getDebug()` → `{enabled, state, volume, master}`。

## 3. 运行时验证（`scripts/verify.mjs`）

- 背景音乐开关 + 音量控件常驻，默认开启且默认音量 65%；
- 首次用户手势后 `AudioContext.state === 'running'` 且主增益淡入（>0.15）；
- 关闭后主增益归零（<0.03）并挂起；可重新开启（恢复 running）；
- 移动端：开关可见可用；
- **音频会话隔离**：验证主流程以「音乐关闭」偏好启动（evaluateOnNewDocument 注入），
  音频相关断言在文末独立短会话中执行并清理——无头软渲染环境下音频线程偶发长帧，
  隔离后不会污染 300+ 交互检查的时序；
- 验证器启动时带 `--autoplay-policy=no-user-gesture-required`，保证音频断言在无头环境确定性。

## 4. 答辩口径

- **问：音乐文件哪来的？版权吗？** 没有音频文件。全部是 Web Audio 实时合成的氛围音乐，
  旋律/音色均为本项目编写，无版权风险；断网也能播放。
- **问：会不会影响性能？** 音频图仅 ~15 个振荡/噪声节点，远低于 3D 渲染成本；
  切到后台自动挂起，关闭后自动淡出并停止调度。
- **问：能换成品音乐吗？** 可以：把 `StarfieldMusic` 替换为 `<audio loop>` 接入
  `public/audio/xxx.mp3` 即可，控制台开关/音量/持久化逻辑不变（接口为
  `enable / disable / setVolume / suspend / resume`）。
- **问：为什么默认开？** 背景音乐是氛围的一部分；遵守浏览器策略只在用户首次操作后出声，
  随时可一键关闭并记住选择。

## 5. 响度上调记录（v2）

用户在试用后反馈"总体调大一点"，做了一次整体响度上调（约 1.7×）：

| 调整项 | 旧值 | 新值 |
| --- | --- | --- |
| 默认音量 | 45% | **65%**（滑杆上限 100% 不变） |
| 主增益换算 | 音量 × 0.9 | 音量 × 1.0 |
| 铺底振荡（每音双振荡） | 0.050 / 0.040 | 0.060 / 0.048 |
| 铺底总线 | 0.80 | 0.85 |
| 和声层峰值 | 0.022 | 0.028 |
| 钟琴峰值 | 0.055 | 0.075 |
| 空间风噪 | 0.018 | 0.023 |
| 软压缩器阈值 | -20dB | -18dB（更早介入，峰值更整齐） |

- **老偏好迁移**：本地已保存的音量按 1.4× 上调（封顶 90%），开关状态保留；
  偏好结构带版本号 `v: 2`，迁移只执行一次。
- 音量滑杆随时可回调；压缩器保证大音量下无削波。
