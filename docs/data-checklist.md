## 0. 总览：三个星系

「知识宇宙」按**科目 = 星系**组织，每个星系内部结构完全同构：章节 = 星团、考点 = 星球、关联 = 连线、掌握度 = 颜色亮度。左侧「星系」切换器热切换整张星图，账号做题记录与掌握度跨星系共享。

| 星系 | 星系 id | 星团 | 考点 | 高频 | 题目 | 关联 | 大纲覆盖 |
|---|---|---|---|---|---|---|---|
| 高等数学 | `advanced-math` | 9 | 66 | 25 | 70 | 98 | 数一/二/三 |
| 线性代数 | `linear-algebra` | 6 | 24 | 10 | 25 | 28 | 三卷同纲 |
| 概率论与数理统计 | `probability` | 6 | 28 | 14 | 31 | 37 | 数一/数三 |
| **合计** | **3 星系** | **21** | **118** | **49** | **138** | **163** | — |

规模原则：每章 4–12 个考点（Fibonacci 球面布局在此密度下不拥挤，星团环半径 68、弦长 ≈46.5 > 星团直径 34）；每考点至少 1 道题，保证任意星球点开后「开始做题」都有真实内容；高频考点约占 40%，视觉上更大更亮，形成疏密节奏。

**大纲适用科目（examScope）**：每个考点标注 `[1]` 数一 / `[2]` 数二 / `[3]` 数三 的子集，信息面板以「大纲」徽标行展示（不考科目划线置灰）。全站分布：三卷通考 61、仅数一 21、数一+数二 4、数一+数三 31、仅数三 1。关键边界：

- 数学二**不考概率论**（数二 = 高数 + 线代）；线代三卷同纲
- 高数：伯努利/全微分/欧拉方程、方向导数梯度、三重积分、线面积分仅数一；差分方程仅数三
- 概率：估计量评选标准、区间估计、假设检验仅数一（数三概率只到参数估计）

章节掌握度初始值 = 章内已测考点均分（未学不计入）：

- **高等数学**：极限 71 / 导数 54 / 积分 54 / 向量 57 / 多元 39 / 重积分 47 / 线面积分 未开始 / 级数 37 / 方程 59
- **线性代数**：行列式 78 / 矩阵 80 / 向量组 58 / 方程组 66 / 特征值 36 / 二次型 33
- **概率论**：事件 63 / 一维分布 44 / 多维 25 / 数字特征 未开始 / 大数定律 未开始 / 数理统计 未开始

故事线设计（为什么这样分布）：

- **三个星系三种状态**：高数"推进到多元/重积分，线面积分未攻克"；线代"一轮过完基础扎实，特征值/二次型二轮待补"；概率"刚翻开，数字特征之后全覆盖未学"。切换星系即切换复习阶段，叙事一眼可读。
- **每团至少 1 个薄弱点**（未学团除外）：橙红脉冲是视觉焦点，高数的泰勒/链式法则、线代的对角化/正定、概率的多维/一维函数分布是最亮的橙色焦点。
- **线面积分整团未学** + 概率后三团"未开始"：制造"尚未征服的星域"，为演示做题点亮星球留出戏剧性落点。
- **高频考点优先给状态**：49 个高频考点中 30 个已有学习记录，大而亮的星球有颜色。
- 此后由规则引擎按做题记录加减维护（见 `docs/mastery-and-records.md`），做题结算后自动刷新星团标签。

关键链路（演示关联跳转的推荐路径）：

```
高数：limit-inf → der-def → der-diff → int-def → int-calc → ode-separable
      int-definite → mi-def → mi-calc → li-green → ode-exact（一题多链的枢纽）
线代：矩阵运算 → 初等变换 → 秩 → 向量组秩 → 齐次方程 → 特征值 → 对角化
      → 实对称 → 二次型标准形 → 惯性定理 → 正定
概率：条件概率 → 贝叶斯；分布函数 → 离散/连续 → 函数分布；联合 → 边缘 → 独立 → 协方差
      方差 → 切比雪夫/CLT → 抽样分布 → 矩估计/最大似然 →（数一）区间估计 → 假设检验
```

约束：前置依赖不允许成环（校验脚本 DFS 三色检测）；不允许自环与重复边；每个考点至少 1 条关联（无孤立星球）。

## 6. 题库设计

138 题（121 单选 + 17 填空），难度 1 档 36 / 2 档 75 / 3 档 27，答案与解析逐题验算；填空题判分前做归一化（去空白/小写/上标转 ^/全角括号转半角），`accept` 列表收录等价写法。

- **抽题规则**：`getQuestionsForPoint()` 按考点关联抽题、难度升序、最多 3 道——先易后难。
- **多考点题**（如 `q-der-05`），用于"一题多考点"的掌握度分摊。
- **跨章题**（`q-der-05` 导数章挂极限考点；`q-zy-07` 概率事件章挂独立性考点）：校验脚本给 WARN 而非 ERROR，属刻意的知识串联。
- 解析写"为什么"而非仅报答案（如 |kA| 漏乘阶数幂次、协方差公式记错符号），支撑薄弱考点的复习闭环。

### 6.1 2026-11-20 题型改编批次（12 题）

按用户提供的《张宇考研数学题源探析经典1000题·数学一·解析分册》（北京理工大学出版社，扫描版）的**题型与考点结构**，改编录入 12 道演示题：**7 道单选**（`q-zy-01/02/04/06/07/09/11`）**+ 5 道填空**（`q-zy-03/05/08/10/12`），覆盖高数 / 线代 / 概率共 11 个章节。

- 说明 1：该 PDF 为**解析分册**，页面只有答案与解析、不含完整题干（题干在原书习题册中），因此无法逐题还原录入；
- 说明 2：书籍版权归原作者 / 出版社，本项目未逐字复制，题目数值与解析为改写并逐题验算，仅作学习演示；
- 说明 3：难度 1 档 7 题、2 档 5 题；全部通过 Schema、公式渲染与 UI 泄漏守卫校验。
