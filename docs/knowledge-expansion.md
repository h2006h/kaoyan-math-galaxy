### 1.3 线代 / 概率论大纲范围（第二轮核实的结论）

线性代数三卷同纲，共 6 个单元：**行列式、矩阵、向量、线性方程组、特征值和特征向量、二次型**。数一/数三均不要求"向量空间、基、维数"（大纲原文无此条目），故 24 个线代考点 `examScope` 全部为 `[1,2,3]`。

概率论与数理统计 8 个单元（随机事件和概率 / 随机变量及其分布 / 多维随机变量及其分布 / 数字特征 / 大数定律和中心极限定理 / 数理统计基本概念 / 参数估计 / 假设检验），其中：

| 考点 | 数一 | 数三 | 依据 |
|---|---|---|---|
| 概率论全部（随机事件 → 大数定律/CLT，含条件分布、二维函数分布） | ✓ | ✓ | 数三考试内容含全部七部分 |
| 抽样分布（χ²/t/F）、矩估计、最大似然估计 | ✓ | ✓ | 数三"掌握矩估计法和最大似然估计法" |
| 估计量的评选标准（无偏/有效/一致） | ✓ | ✗ | 数三大纲不含 |
| 区间估计 | ✓ | ✗ | 数三大纲不含 |
| 假设检验 | ✓ | ✗ | 数三大纲不含 |

> 与线代相反，概率的差异在**统计后半段**：数三只到"参数估计"，评选标准 / 区间估计 / 假设检验三种仅数一。数二不考概率论与数理统计（数学二考试科目为高数 + 线代）。本项目概率星系 28 考点中 25 个 `[1,3]`、3 个仅 `[1]`。

## 5. 答辩口径

- **问：知识点全吗？** 站内现有 3 个星系：高等数学（同济七版 12 章 → 9 星团 66 考点）、线性代数（6 单元 24 考点）、概率论与数理统计（8 单元 → 6 星团 28 考点），全部按考研大纲口径覆盖。
- **问：数据哪来的，会不会是编的？** 章节与考点目录来自同济七版教材目录（当当详情页可核对），数一/二/三范围逐条对照大纲原文（中国教育在线/新东方存档），来源链接见本文 §1。题目是命制的演示题而非真题，答案均经人工验算——这一点如实说明。
- **问：数二考伯努利方程吗？** 不考。以大纲原文为准：伯努利/全微分/欧拉仅数一；网上许多二手资料有误，本项目 examScope 字段按原文标注并在星球面板展示。
- **问：数三考假设检验吗？** 不考。数三概率只到参数估计（矩估计 + 最大似然），评选标准/区间估计/假设检验三种仅数一（`examScope:[1]`，星球面板中以划线徽标呈现）。
- **问：三个星系怎么切换？** 左侧「星系」切换器，切换时整张星图热替换（星球/连线/星团标签重建、控制台视觉开关沿用），做题记录与掌握度跨星系共享同一账号状态。
- **问：为什么有的星球面板"数二/数三"划线？** 该考点不在对应科目大纲内（如曲率仅数一/二），划线徽标让考生一眼知道"我要不要学这颗星"。
