# 相关题目与参考答案公式显示（Markdown 解析）· 设计与答辩口径

> 「相关题目」与「参考答案/解析」里的公式，统一转换为 **Markdown 数学语法（`$…$`）**，
> 由与知识讲解页完全相同的 **Markdown + KaTeX** 管线解析渲染。
> 题库仍是手写的 Unicode 数学文本，**数据一个字不改**，转换是显示层的自动增强。

## 1. 渲染链路（与知识讲解同一条管线）

```
题库文本（题干 / 参考答案 / 解析，Unicode 数学）
  └─ mathParse.splitMathSegments   切分普通文本与数学片段（保守判定）
  └─ mathParse.toMarkdownMath      数学片段包成 $…$；普通文本里的 \* _ ` # > 转义
  └─ markdown.renderInlineMarkdown 行内 Markdown 解析 + KaTeX 渲染（与讲解页同一函数）
  └─ MathText 组件                 首次出现公式时按需加载 KaTeX 与样式，失败回退原文
```

- **应用位置**
  - 考点练习结算页：参考答案行（单选给完整正确选项正文、填空给接受答案）、整段解析、填空答案提示；
  - 知识讲解页「相关题目」：**题干**、参考答案、解析。
- **零数据迁移**：不修改 `question_bank.json`；识别保守、解析失败即原样显示。
- **主包零增重**：KaTeX 与样式只在首次出现公式时加载（与讲解页共享缓存）。

## 2. 转换规则（mathParse.js）

- **切分**：中文与全角标点自然切断数学片段；连续下划线（填空题空位 `____`）强制按普通文本处理。
- **保守判定**：纯英文单词/缩写、1–4 位纯数字、含中文片段一律不转换；
  单变量、函数式 `f(x)`/`P(A)`、括号组 `[a,b]`、含运算符/上下标/数学符号的片段才排版。
- **Unicode → LaTeX**：
  - 上下标成组：`x²→x^{2}`、`A⁻¹→A^{-1}`、`eˣ→e^{x}`、`∫₀ˣ→\int_{0}^{x}`；
  - 函数：`sinx→\sin x`、`lim(x→0)→\lim (x\to0)`、`tr→\operatorname{tr}`、`d/dx→\frac{d}{dx}`；
  - 符号：`→ ⇒ ⇔`、`· × ÷ ±`、`≤ ≥ ≠ ≈ ≡`、`∈ ∪ ∩`、`∫ ∮ ∯ ∑ ∏ √ ∞`、希腊字母、`x̄→\bar{x}`；
  - 下标紧跟命令词补花括号：`∫∫_Σ → \int\int_{\sum}`。
- **Markdown 转义**：文本中的 `*`（如 `A*`、`y*`）、`_`、反引号、`#`、`>` 会转义，
  不会被 Markdown 当成强调/代码；由渲染器统一还原为字面字符。
- **兜底**：单片段解析失败时回退该片段原文，页面上不会出现红色错误。

## 3. 数据校验（scripts/validate-data.mjs）

对 126 题的 **题干 + 解析 + 参考答案** 走与界面完全相同的渲染路径
（`toMarkdownMath → renderInlineMarkdown`），出现 `katex-error` 即校验失败：

- 378 条文本 · 317 条含公式 · **712 个数学片段，0 失败**；
- 知识讲解页自身（118 篇 / 1130 条公式）校验保持 0 失败。

## 4. 运行时验证（scripts/verify.mjs）

- 练习结算页：参考答案行存在、解析区公式渲染、`.katex-error` 为 0、可见文本无 `$`/LaTeX 泄漏；
- 讲解页相关题目：**题干与参考答案同时渲染**公式，无错误、无泄漏；
- 118 项全量检查继续覆盖做题/结算/账号隔离等原有逻辑。

## 5. 全站泄漏扫描与覆盖面（2026-11-20 复查）

对全部 UI 展示文本做了两层扫描：

- **数据层**：知识库（科目/章节/考点名与简介）+ 题库（题干/选项/答案/解析）共 988 条字段，
  **0 处 `$` 定界符、0 处反斜杠 LaTeX 命令**；另有 22 处 `^{…}`/`_{…}` 风格裸片段，
  已全部纳入 Markdown 公式管线渲染（信息面板简介、练习题干与选项、管理台卡片、
  小智离线回答、讲解页相关题目）。
- **页面层**（真实浏览器逐页）：登录页、星图俯瞰、「星系切换」、信息面板、考点练习
  （题干/选项/参考答案/解析）、知识讲解（正文 + 相关题目）、题库管理台、小智面板、移动端；
  剔除 KaTeX 节点后的可见文本均无 `$`、`\命令`、`^{`、`_{` 泄漏。
- 自动化守卫：`validate-data` 扫描全部 UI 字段禁用 `$`/LaTeX 命令；
  `verify` 覆盖练习题干、参考答案、信息面板简介、讲解页相关题目的「无泄漏」断言。

## 6. 边界与答辩口径

- **范围**：UI 中只读的公式文本全部走 Markdown 解析（信息面板简介、练习题干/选项/参考答案/解析、
  讲解页正文与相关题目、题库管理台预览、小智回答）；**可编辑输入框**（题库工作台表单）保持原始文本。
- **问：真的是 Markdown 解析吗？** 是。数学片段被写成 `$…$` 后交给讲解页同一个
  `renderInlineMarkdown`（Markdown 解析 + KaTeX），不是独立的公式拼图。
- **问：会不会误伤文本里的星号？** 题库中 `A*`（伴随矩阵）、`y*`（特解）等星号在转 Markdown
  前已被转义，显示为原字符，不会被当成斜体。
- **问：公式是图片吗？** 不是，KaTeX 文本排版，可选中、可缩放、离线可用。
- **问：会不会拖慢首屏？** 不会。KaTeX 在首次出现公式时才按需加载，主包无增重
  （与知识讲解页共用同一份 KaTeX 资源缓存）。
