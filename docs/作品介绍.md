## 二、你的作品是什么（一句话）

**「考研数学知识宇宙」把考研数学的 118 个考点做成一个可旋转的 3D 知识星系，让考研学生在电脑或手机上"看得见知识结构、点得到讲解和练习、实时看到自己的掌握度变化"。**

一句话补充：它同时覆盖数一 / 数二 / 数三的考试范围差异，内置 118 篇带公式排版的考点讲解与 138 道练习题，并带有可溯源的 AI 助学智能体「小智」。

## 三、为什么做（问题或想法的来源）

备考数学时最痛苦的三个点：

1. **知识是散点**：复习资料、思维导图、网课笔记各自为政，看不出"这个考点依赖哪些前置知识"；
2. **进度不可见**：刷了很多题，但说不清自己"到底哪里薄弱"，容易在会的地方反复投入；
3. **反馈太慢**：做完题看不到知识结构上的变化，很难获得正反馈。

所以我把"知识结构 + 讲解 + 练习 + 掌握度反馈"放进同一个空间：**星团是章节、星球是考点、连线是前置/关联**，颜色和亮度就是掌握度；做对题，星球当场变亮——把抽象的复习进度变成一眼就能看懂的画面。

数据上没有"拍脑袋"：章节与考点目录对照同济版教材，数一/二/三范围逐条核对考研大纲原文（例如数二不考伯努利方程），项目内全部题目均由人工验算；少量参考教辅结构的题目为改写而非照搬（教辅解析册版权归原作者，未逐字录入）。

## 四、怎么用（不超过 5 步，评委可照做）

1. **打开网站**：访问【公开部署地址】（若访问受限，请用本地方式：`npm install` → `npm run dev`），在登录页点「**直接进入演示账号**」。
2. **看星图**：左侧切换「高等数学 / 线性代数 / 概率论」三个星系；鼠标拖拽旋转、滚轮缩放，观察星团与星球。
3. **读讲解**：点击任意星球 →「知识讲解」，查看考点概念、核心公式（Markdown 公式排版）、易错点与相关题目。
4. **做练习**：回到星球面板点「开始做题」→ 提交答案后立刻看到解析与分数变化，**背后的星球颜色会实时更新**。
5. **问小智**：点右下角“智”悬浮球，用自然语言提问（如“泰勒公式属于数几范围？”），回答附可点击的考点引用；顶部可注册自己的账号，记录独立保存。

> 小贴士：演示账号下控制台可开启「背景音乐」、点「模拟做题结果」快速演示掌握度联动；注册账号不提供模拟功能，数据互不污染。

## 五、用 Qoder 做出来的过程（分工 · 我改了什么 · 截图凭证）

整体方式是：**我定产品与规则，Qoder 负责实现与自动化验证，我在每一步做验收和纠偏。** 主要分五步：

1. **数据底座交给它，范围由我拍板。**
   我把同济教材目录与考研大纲要求交给 Qoder，让它生成 3 个星系 / 21 章 / 118 考点 / 163 条关联 / 138 道题的结构化数据，并写数据校验脚本（Schema + 引用完整性 + 公式可解析）。
   **我改的**：逐条修正范围与难度（如数二不考级数、数三假设置信区间），删掉 AI 编造/来源不明的条目。
   *凭证：数据校验通过日志截图（`node scripts/validate-data.mjs`）*

2. **3D 场景与视觉由它生成，审美与性能由我验收。**
   我用自然语言描述"星团-星球-连线"的空间布局和深空氛围，Qoder 实现 Three.js 引擎（泛光、星野、星云、流光、飞行穿越）；之后我根据实机截图连续提了三轮改进：**重新构图星云、去掉天穹照片噪点、解决卡顿（限制像素密度、泛光半分辨率、自适应画质）**。
   **我改的**：明确"不要随机糊点、要四角构图""低配机器必须自动降档"等验收标准。
   *凭证：星云美化前后对比截图、性能优化前后帧时间对比*

3. **学习闭环：规则我定，实现它写。**
   我定义了"答对/答错加减分、连对奖励、账号间记录隔离、管理员 AI 只建议不入库"的规则，Qoder 落地做题抽屉、即时结算、题库导入工作台与后端代理；AI 质检在离线时自动降级，绝不阻塞流程。
   **我改的**：把"AI 自动裁决"改成"AI 建议 + 人工确认唯一入口"。
   *凭证：做题结算截图、导入工作台 AI 建议卡片截图*

4. **讲解与小智：我要求"所有公式必须真排版、回答必须有出处"。**
   Qoder 生成了 118 篇 Markdown 讲解 + KaTeX 渲染（公式可选中、离线可用）、RAG 检索的智能体「小智」（引用白名单、跨星系跳转、离线降级）；并做了登录/注册用户表、程序化星空背景音乐。之后我又要求它**全站扫描公式泄漏**，修复了题干、简介、管理台等处 22 处 `^{…}` 裸文本。
   **我改的**：统一"公式一律 Markdown 解析"的验收标准；要求密码加盐哈希、演示账号专属功能。
   *凭证：公式渲染前后对比截图、用户表结构截图*

5. **质量与上线：它写自动化验证，我跑真机验收。**
   Qoder 搭建了 `verify` 运行时验证脚本，覆盖 **120 项检查**（桌面 + 移动端、账号隔离、跨星系、AI 降级、模式切换等），并在部署前全量通过；最终通过 **Qoder Sites** 发布上线。
   **我改的**：每一轮都按真实浏览器截图验收，发现"移动端按钮被裁切""动画中途量尺寸"等问题并让它修复。
   *凭证：验证 120/120 通过截图、Qoder Sites 发布成功截图*
